# Presentation Design Skill

## Goal
Create professional, visually clear PowerPoint presentations.

## Workflow

1. Understand the presentation topic and audience.
2. Determine the required number of slides.
3. Create a slide-by-slide outline.
4. Assign an appropriate layout to every slide.
5. Generate the presentation.
6. Render the slides and inspect them visually.
7. Fix overflow, alignment, spacing, and readability issues.
8. Re-render and verify the final deck.

## Design Rules

- One main idea per slide.
- Avoid large blocks of text.
- Prefer diagrams, tables, timelines, and visual structures.
- Use consistent typography throughout the deck.
- Maintain generous margins and whitespace.
- Keep alignment consistent.
- Do not randomly change colors or fonts.
- Use visual hierarchy to emphasize important information.
- Never put text too close to the edge.
- Avoid unnecessary animations and decorative elements.

## Academic Presentation Rules

For university presentations:

- Use clear technical terminology.
- Explain concepts progressively.
- Include examples where useful.
- Use diagrams for processes and architectures.
- Keep technical slides understandable when presented verbally.
- Include references when external sources are used.
- Add speaker notes when explanations are important but shouldn't appear on the slide.

## Quality Check

Before finishing:

- Check text overflow.
- Check objects extending outside slide boundaries.
- Check font sizes.
- Check alignment.
- Check contrast.
- Check consistency between slides.
- Render the entire presentation and visually inspect every slide.
