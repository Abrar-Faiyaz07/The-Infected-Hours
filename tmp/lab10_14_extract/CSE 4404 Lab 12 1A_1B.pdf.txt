Task A. GPU Cluster Scheduling
Time Limit: 1 second|Memory Limit: 1536 MB
Imagine you manage a computer system where engineers run AI training jobs on shared graphics cards (GPU
clusters). Each jobiruns during a specific time window, wheres i is the start time andf i is the finish time. The
exact length or duration of each task is mathematically defined as:d i =f i −s i Because two jobs cannot use the
same GPU at the same time, your goal is to find the fewest GPUs needed to run them all. By sorting the jobs
by their start times and automatically reusing a GPU the exact moment a previous job’s durationd i is complete,
you can efficiently schedule the entire workload with the minimum amount of hardware.
Input Format
Each test case starts with a single integerN, representing the total number of jobs. The nextNlines each contain
two integers:s i andf i, representing the start time and finish time of jobi.
Output Format
For each test case, print a single integer representing the minimum number of GPUs required.
Constraints
1≤N≤10 5
0≤s i < f i ≤10 9

Time Limit: 2 seconds|Memory Limit: 512 MB
The screen is overflowing with fruits, each ready to fall if you don’t slice them in time. Each fruitihas a fall time
fi and a point valuep i you earn if you slice it before it falls. You can slice at most one fruit per unit of time, and
must slice a fruit at some integer timet≤f i. Your mission is to slice fruits smartly to maximize your total points
and become the ultimate Fruit Ninja Champion!
Input Format
The first line contains an integerT— the number of test cases.
Each test case consists of:
•A line with an integern— the number of fruits.
•A line withnintegersf 1, f2, . . . , fn — the fall times of the fruits.
•A line withnintegersp 1, p2, . . . , pn — the points for each fruit.
It is guaranteed that the sum ofnover all test cases does not exceed 2×10 5.
Output Format
For each test case, print a single integer — the maximum total points you can earn.
