Task A. Ring of Villages
Time Limit: 1 second|Memory Limit: 1536 MB
Daiyan is exploring a country consisting ofnvillages arranged sequentially in a circle, labeled 1 throughnin
clockwise order (100≤n≤10 18).
For any ordered pair of distinct villages (u, v), villagers always follow a fixed directional path, either strictly
clockwise or strictly counter-clockwise. When queried about the distance fromutov, the answer provided is
d(u, v), the number of step edges along that chosen directional path.
For each ordered pair (u, v), the path direction is chosen independently with equal probability (50% clockwise,
50% counter-clockwise) and remains fixed throughout all queries. Note that the direction chosen for (u, v) is
independent of the direction chosen for (v, u).
To monitor traffic, Daiyan selected 100 of thenvillages and tagged each with asample idfrom 1 to 100 for
record-keeping.These sample ids are arbitrary bookkeeping labels only— sample idiis not necessarily
the village that is physically labelediin the ring’s clockwise numbering, and the mapping between sample ids
and actual ring positions is not given to you. The same sample id always refers to the same underlying village
throughout the log.
You are given the logged directional path distances fortdistinct ordered pairs of sample ids (a, b) such that
1≤a, b≤100 anda̸=b(out of the 100×99 = 9,900 possible such pairs). If a distance is unknown or invalid, it
is represented as−1. Determine the total number of villagesn. It is guaranteed that the logged queries uniquely
determinen.
Input Format
The first line contains a single integert(1≤t≤9,900) — the number of logged queries.
Each of the nexttlines contains three integersu,v, andx(1≤u, v≤100,u̸=v), representing a query where the
reported directional path distance from the village with sample iduto the village with sample idvisx(x=−1
or 1≤x <10 18). A value ofx=−1 indicates that the distance is unknown or invalid. No ordered pair (u, v)
appears more than once in the input.
Constraints:
100≤n≤10 18
1≤t≤9,900
1≤u, v≤100,u̸=v
x=−1 or 1≤x <10 18
No ordered pair (u, v) appears more than once in the input.
It is guaranteed that the input data is consistent with a unique value ofn.
Output Format
Print a single integer representingn, the total number of villages.

Task B. Huffman Compression
Time Limit: 1 second|Memory Limit: 1536 MB
Given a stringSconsisting only of lowercase English letters, your task is to construct an optimal Huffman code
forSand output the exact binary code assigned to each distinct character.
Unlike the total-bit-count version of this task, the assignment of individual codes to characters isnotunique in
general Huffman coding. To make the output well-defined, ties are broken deterministically: when merging the two
least frequent nodes, an original leaf is preferred over a merged node, and among leaves, the alphabetically smaller
character comes first. The edge to the first node merged is labeled0and to the second1, and each character’s
code is the sequence of edge labels from the root to its leaf. IfScontains only 1 unique character, its code is
defined to be0.
Input Format
The input consists of a single line containing a non-empty stringS(1≤ |S| ≤10 5), consisting only of lowercase
English letters (’a’–’z’).
Output Format
Letkbe the number of distinct characters inS. Printklines, each containing a character ofSfollowed by a single
space and its binary Huffman code (as produced by the construction above), with no leading zeros stripped and
no other characters. The lines must be sorted in alphabetical order of the character.
Examples
Sample Input Sample Output
abracadabra a 0
b 110
c 100
d 101
r 111
aaaaa a 0

Task C. Estimating PI
Time Limit: 1 second|Memory Limit: 512 MB
You are asked to estimate the value of the mathematical constantπusing the Monte Carlo method.
The idea is simple: if we randomly place points inside a square of side length 1, the probability that a point lies
inside the quarter circle of radius 1 (inscribed in the square) isπ/4.
Generatenrandom points, your job is to count how many of them fall inside the quarter circle, and then use this
to estimateπ.
Input Format
The input contains a single integer, which is always 1. You must read this integer, but it has no use in your
calculation.
Output Format
Print a single real number representing the estimated value ofπ, rounded to 2 decimal places.
Examples
Sample Input Sample Output
1 3.14
Notes
Use thegenerate randomfunction provided in the submission folder to generate random numbers.
