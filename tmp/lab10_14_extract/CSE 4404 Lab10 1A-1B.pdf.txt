Task A. Divide and Conquer Convex Hull
Time Limit: 2.0 seconds|Memory Limit: 1536 MB
Given a set ofNdistinct points on a two-dimensional plane where no two points share identicalXorYcoordinates,
your objective is to find the vertices that form theConvex Hullof these points in a strictClockwise (CW)
order.
To achieve optimal performance constraints, you are required to implement thePreparata-Hong Divide and
Conqueralgorithm:
1. Sort all points globally by theirX-coordinate (breaking ties withY-coordinates).
2. Recursively divide the sorted set into left and right halves.
3. For base cases containing 5 or fewer points (≤5), compute the convex hull directly using aBrute-Force
method, ensuring the returned subset is oriented clockwise.
4. Merge the two independent clockwise sub-hulls back together using thetwo-finger tangent walking
methodto find both the upper and lower common tangents, subsequently applying acut-and-paste
step to stitch the outer boundary cleanly.
Output Sequence Requirement
The output configuration requires specific formatting to be accepted by the structural test judge:
•The convex hull vertices must be printed as a single space-separated sequence of their original, 1-based input
indices.
•The sequence must follow a continuousClockwiseperimeter.
•Crucial Boundary Condition:The output cycle must be cyclically shifted/rotated so that the point with
theearliest original input index(the point that appeared first in the input list, which bears the minimum
Tracking ID) is positioned at the very beginning of the output sequence.
Input Format
The first line contains a single integerN, representing the total number of points on the plane.
The nextNlines each contain two space-separated integersx i andy i, denoting the coordinate plane positions of
thei-th point.
Output Format
Print a single line containing the original 1-based indices of the points that form the convex hull, ordered clockwise
and beginning with the earliest input index point.
Constraints
3≤N≤10 5
−109 ≤x i, yi ≤10 9
Allx i coordinates are distinct.
Ally i coordinates are distinct.
