Task A. Ring of Villages
Time Limit: 1 second|Memory Limit: 1536 MB
Daiyan is exploring a country consisting ofnvillages arranged sequentially in a circle, labeled 1 throughnin
clockwise order (100≤n≤10 18).
For any ordered pair of distinct villages (u, v), villagers always follow a fixed directional path, either strictly
clockwise or strictly counter-clockwise. When queried about the distance fromutov, the answer provided is
d(u, v), the number of step edges along that chosen directional path.
For each ordered pair (u, v), the path direction is chosen independently with equal probability (50% clockwise,
50% counter-clockwise) and remains fixed throughout all queries. Note that the direction chosen for (u, v) is
independent of the direction chosen for (v, u).
You are given the logged directional path distances for all 100×99 = 9,900 distinct ordered pairs of villages (a, b)
such that 1≤a, b≤100 anda̸=b. If a distance is unknown or invalid, it is represented as−1. Determine the
total number of villagesn. It is guaranteed that the logged queries uniquely determinen.
Input Format
The input consists of 9,900 lines.
Each line contains three integersu,v, andx(1≤u, v≤100, u̸=v), representing a query where the reported
directional path distance fromutovisx(x=−1 or 1≤x <10 18). A value ofx=−1 indicates that the distance
is unknown or invalid. The input contains all possible ordered pairs (u, v) for 1≤u, v≤100 (u̸=v).
Output Format
Print a single integer representingn, the total number of villages.
Constraints
100≤n≤10 18
1≤u, v≤100, u̸=v
x=−1 or 1≤x <10 18
The input contains all 9,900 ordered pairs (u, v) with 1≤u, v≤100 andu̸=v.
It is guaranteed that the input data is consistent with a unique value ofn.

Task B. Huffman Compression
Time Limit: 1 second|Memory Limit: 1536 MB
Given a stringSconsisting only of lowercase English letters, your task is to determine the minimum number of
bits required to representSusing optimal Huffman coding.
In Huffman coding, each unique character in the string is assigned a unique variable-length binary code such that
no code is a prefix of another. The tree is built by repeatedly merging the two least frequent nodes until only one
tree remains:
•The length of the binary code assigned to a character corresponds to its depth in the optimal Huffman tree.
•Total bits required is P(frequency ofc×length of code forc).
•IfScontains only 1 unique character, each instance requires 1 bit.
Input Format
The input consists of a single line containing a non-empty stringS(1≤ |S| ≤10 5), consisting only of lowercase
English letters (’a’–’z’).
Output Format
Print a single integer representing the minimum total number of bits required to encode the stringS.
Constraints
1≤ |S| ≤10 5
Scontains only lowercase English letters (’a’–’z’).
Examples
Sample Input Sample Output
abracadabra 23
aaaaa 5

Task C. Estimating PI
Time Limit: 1 second|Memory Limit: 512 MB
You are asked to estimate the value of the mathematical constantπusing the Monte Carlo method.
The idea is simple: if we randomly place points inside a square of side length 1, the probability that a point lies
inside the quarter circle of radius 1 (inscribed in the square) isπ/4.
Generatenrandom points, your job is to count how many of them fall inside the quarter circle, and then use this
to estimateπ.
Input Format
The input contains a single integer, which is always 1. You must read this integer, but it has no use in your
calculation.
Output Format
Print a single real number representing the estimated value ofπ, rounded to 2 decimal places.
Constraints
The input integer will always be 1.
Examples
Sample Input Sample Output
1 3.14
(Use the generate random function provided in the submission folder to generate random numbers)
