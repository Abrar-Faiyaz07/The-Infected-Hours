Task A. Divide and Conquer Convex Hull
Time Limit: 2 seconds|Memory Limit: 1536 MB
Given a set ofNdistinct points on a two-dimensional plane, where no two points share identicalXorYcoordinates,
find the vertices that form theconvex hullof these points in strictclockwise (CW)order.
To achieve optimal performance, you are required to implement thePreparata–Hong Divide and Conquer
algorithm:
1. Sort all points globally by theirX-coordinate (breaking ties withY-coordinates).
2. Recursively divide the sorted set into left and right halves.
3. For base cases containing 5 or fewer points (≤5), compute the convex hull directly using a brute-force
method, ensuring the returned subset is oriented clockwise.
4. Merge the two independent clockwise sub-hulls back together using thetwo-finger tangent walking method
to find both the upper and lower common tangents, then apply a cut-and-paste step to stitch the outer
boundary cleanly.
Output Sequence Requirement:
The convex hull vertices must be printed as a single space-separated sequence of their original, 1-based input
indices.
The sequence must follow a continuous clockwise perimeter.
Crucial boundary condition:the output cycle must be cyclically shifted/rotated so that the point with
the earliest original input index (the point that appeared first in the input list) is positioned at the very
beginning of the output sequence.
Input Format
The first line contains a single integerN(3≤N≤10 5) — the total number of points on the plane.
The nextNlines each contain two space-separated integersx i andy i (−109 ≤x i, yi ≤10 9) — the coordinates of
thei-th point. Allx i coordinates are distinct, and ally i coordinates are distinct.
Output Format
Print a single line containing the original 1-based indices of the points that form the convex hull, ordered clockwise
and beginning with the earliest input index point.

A skeleton C++ file is provided in the submission folder, where most functions are already implemented. You

1.comparePoints: used to sort the points byxvalue.
2.isValid: checks if all the points fall on the right side of the current line.
3.getYIntersection: finds theyvalue of the intersection of the vertical line and the line formed by connecting
two points from both sides.
4.findUpperTangent: finds the two points forming the upper tangent.
5.combine: returns the sequence of points after combining two polygons, given the upper and lower tangent
points.
6.mergeHulls: uses all the functions above to merge two convex polygons.
