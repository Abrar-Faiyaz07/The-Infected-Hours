Ford-Fulkerson Algorithm
• Initialize maxflow as 0
• While there is augmenting path
• Determine the flow possible through the augmenting path
• Add that flow to the maxflow

===== PAGE 7 =====
Edmond-Karp Algorithm
• Ford-Fulkerson is a more general method that doesn't specify how 
to find augmenting paths.
• Edmonds-Karp is a specific implementation that uses Breadth-First
Search (BFS) to find the shortest augmenting paths (in terms of
number of edges, not the sum of weights of edges).
