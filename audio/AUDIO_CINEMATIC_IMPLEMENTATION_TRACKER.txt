5. RELEVANT CODE FILES
----------------------

core/src/main/java/com/infectedhour/core/audio/AudioDirector.java
  Loads, caches, plays, stops, and disposes music, voice, and SFX safely.

core/src/main/java/com/infectedhour/core/audio/SoundtrackCatalog.java
  Defines stable runtime OGG paths for music and catalogued SFX.

core/src/main/java/com/infectedhour/core/content/DialogueCatalog.java
  Defines dialogue IDs, speakers, subtitle text, and runtime voice paths.

core/src/main/java/com/infectedhour/core/screens/StoryPanelScreen.java
  Displays intro/interlude/ending images and text. Narration is not wired yet.

core/src/main/java/com/infectedhour/core/screens/LevelBriefingScreen.java
  Displays the mission briefing image and starts the mapped level music.

core/src/main/java/com/infectedhour/core/screens/MainMenuScreen.java
  Starts main-menu music.

core/src/main/java/com/infectedhour/core/screens/BossScreen.java
  Starts boss music and boss-title voice. Level 6-owned; do not modify unless
  explicitly requested.

fx-launcher/src/main/java/com/infectedhour/fxlauncher/views/SettingsView.java
  Displays volume sliders; handoff notes say they are not fully connected to
  AudioDirector or persistent settings yet.

ASSETS_CREDITS.md
  Must list the creator/source/license for every externally sourced asset.

-------------------------------------------

[ ] Confirm the runtime OGG path matches DialogueCatalog or SoundtrackCatalog.
[ ] Confirm the relevant screen/gameplay system actually requests playback.
[ ] Test advance/skip/leave so narration cannot overlap.
[ ] Test with the OGG temporarily absent; the game must continue safely.
[ ] Add source and license information to ASSETS_CREDITS.md.
[ ] Change this tracker entry from MISSING/NOT WIRED to its new status.
